# Curso PRL · Personal de limpieza

Curso PRL art. 19 Ley 31/1995 para el puesto de personal de limpieza (Previjob). Contenido genérico, válido para el puesto en cualquier centro.

- Web: https://curso-prl-personal-limpieza.onrender.com
- Panel único de administración: https://curso-prl-taf-api.onrender.com/admin/?curso=lim
- API compartida: curso-prl-taf-api (código de curso `lim`, PRL-LIM)

Estructura: `src/m*.js` (contenido), `src/engine.js`, `src/template.html`. Generar con `cd src && python3 build.py` → `index.html`, `admin/index.html`, `course-meta.json`.
